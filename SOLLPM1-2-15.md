## Precendence Dagramming Method

Technique sed for constructing a schedule model in which acts are represented by nodes and graphically linked by one or more logical relationships 

Finish to Start (FS) 
	Logical relationship in which a successor activity cannot start u ntil predecessor actitivy has finished. this is sequential
Finish to Finish (FF)
	Logical relatiuonship which a successor activity cannot finish until a predecessor activity has fnished. writing a document (pre) is required to finish before editing the document (suc) can finish.
Start to Start (SS)
	Successor cannot start until predecessor has started. leveling concrete (suc) cannot being until pouring foundation (pre) begins
Start to Finish (SF)
	Logical relationship which a predecessor act cannot finish until successor act has started. New accounts payable system (suc) has to start before old account payable system can be shut down (pre)
