## Properties of Virtualization

1. Partitioning 
	- divide resrouces between vms
	- run multiple os or vms in single physical amchione
2. Isolation
	- reduce risk of conflict in dependencies
3. Encapsulation
	- move and copy as files
	- improve portability
4. Hardware Independence
	- provision or migrate to any server without the need to perform reconfigs on vm

## Server Virtualizoation

- Enable multi OS to run on a single physical server

- Partitions a physical server into multiple virtual servers

**Benefits**
- Greater IT efficiencies
- Reduced operating costs
- maxizimation of resource
- increased application performance since technically magisa sila. and kahit isolated sila, theyre still physically near each other
- higher server availability
