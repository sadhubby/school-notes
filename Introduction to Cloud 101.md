

# Module 2 - Introduction to Cloud Computing

Modern computing is based client-server model

A **client** can be a web browser or desktop application
A **server** can be services such as *Amazon Elastic Compute Cloud (Amazon EC2), a type of virtual server*.


## 6 Benefits of Cloud Computing
- Trade upfront expense for variable expense
- Stop spending money to run and maintain data centers
- Stop guessing capacity
- Benefit from massive economies of scale
- Increase speed and agility
- Go global in minutes

## Deployment models
Cloud service and deployment methods provide different levels of control, flexibility and management

**Deployment Models**:
1. Infrastructure as a Service (IaaS)
2. Platform as a Service (PaaS)
3. Software as a Service (Saas)

**Deployment Strategies**:
1. Cloud
2. Hybrid
3. Traditional (On-Premise)
4. Community


### IaaS
Basic building blocks for cloud IT. Provides access to networking features, computers (virtual or otherwise) and data storage space. Infrastructure as a service provides highest level of flexibility and management control
	**Products of Amazon**
		1. Amazon EC2
		2. Amazon Simple Storage Service (Amazon S3)
		3. Amazon Relational Database Service (Amazon RDS)
		4. Amazon Route 53 

### PaaS 
Removes the need of orgs to manage the underlying infrastructure. Focus on deployment and management of applications. Gives developers ability to be more efficient because they don't need to worry about resource procurement, capacity planning, software maintenance and patching
	**Products of Amazon**
		1. AWS Elastic Beanstalk - Quickly deploying and scaling web apps

### SaaS
Completed software product that the service provider runs and manages. No need to think about how the service is maintained or how the underlying infrastructure is managed. Just think about how you will use the software.

### Cloud Deployment
Migrate existing applications to the cloud or design and build new applications in the cloud. You can build those applications on low-level infrastructure that requires IT to manage them 

### Hybrid Deployment
Cloud-based resources are connected to on-premises infrastructure. Can integrate cloud-based resources with legacy IT applications. Use this approach in a number of situations. 

### On-premises Deployment
Deployment is also known as a private cloud deployment. In this model, resources are deployed on premises by using virtualization and resource management tools. Increase resource utilization by using application management and virtualization technologies.
